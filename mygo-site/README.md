# MyGO!!!!! 中文介绍页

一个可以直接在 VS Code 中编辑的静态专题网页，以 MyGO!!!!! 的蓝白舞台制服为视觉主题。

## 页面内容

- 乐队与动画介绍、五位成员角色档案、角色声优与现实乐队位置
- 官方高清主视觉、用户提供的动画剧照与演出合影
- 包含 11 首用户提供音频的本地离线播放器
- 可切换的哔哩哔哩 MV、现场与动画预告播放器
- 官方唱片展示：《迷跡波》《跡暖空》《壱雫空》《聿日箋秋》
- 歌曲短句与原创人生解读，不转载完整歌词
- 高质量剧照合影画廊与图片灯箱

## 推荐打开方式

请双击桌面的 `MyGO Site.lnk`。快捷方式会运行 `launch.ps1`，在本机启动 HTTP 服务并打开：

`http://127.0.0.1:4175/`

建议通过快捷方式或 Live Server 打开。音乐文件保存在项目内，可以离线播放；哔哩哔哩视频仍需要连接国内网络。

在 VS Code 中也可以使用 Live Server 打开页面。

## 素材说明

- `assets/user/`：用户此前提供的角色与乐队图片
- `assets/moments/`：用户本次提供的动画剧照、合影与演出画面
- `assets/official/`：BanG Dream! 官方乐队主页与动画官网素材
- `assets/albums/`：BanG Dream! 官方唱片页面的封面
- `assets/audio/`：用户提供并用于本地播放的 MP3 文件
- `assets/media/`：视频列表封面，视频由哔哩哔哩播放器在线播放
- `assets/stills/`：动画官网 Story 页的官方剧照
- Pixiv 作品仅提供标签页链接，没有擅自转载
- 本地音乐文件仅用于本项目的离线展示，请在拥有合法使用权的范围内使用
