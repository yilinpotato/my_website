# QQ 官方机器人

普通消息会得到使用提示；私聊发送 `123456`、`JM123456`、`/jm 123456` 或 `漫画 123456` 默认只返回网页链接，群聊需 @机器人后发送。`网页 123456`（或 `只发网页 123456`）同样只回链接；`压缩包 123456`（或 `zip 123456`）才准备并发送 ZIP；`图片 123456`（或 `只发图片 123456`）仅发送图片，每批最多 3 张，`图片 123456 4` 从第 4 页继续。图片模式不自动改发网页或 ZIP，失败时回具体错误。图片上传使用 file_data，不开放额外公开图片路由。网站原密码保护保持有效。

新版 [QQ 官方富媒体文档](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/rich-media.html) 支持 `file_type=4` 普通文件，最大 200 MB。使用预上传、分片 PUT、分片确认和合并接口上传，再发送文件卡片；直发失败或超限时尝试 24 小时有效下载链接，链接消息仍受平台域名配置限制。需要订阅 `C2C_MESSAGE_CREATE`、`GROUP_AT_MESSAGE_CREATE`，并将服务出口 IP 加入平台 IP 白名单。回调地址保持 `https://potatoma.me/qq/callback`。

## 启动

安装 `requirements.txt`，参照 `.env.example` 将配置写入服务环境变量（程序不自动读取 `.env`）。不要将密钥写入代码；旧代码曾包含密钥，建议在平台轮换。

```sh
gunicorn -w 1 --threads 8 -b 127.0.0.1:5003 jm_bot:app --timeout 300
```

支持 Linux 多 worker：SQLite 共享消息去重、诊断和任务状态；消息线程池与漫画任务线程池各 4 个线程。每个 worker 回复队列最多 16 条、漫画任务最多 8 条；网页任务另设最多 16 条的有界队列。真实下载使用跨进程文件锁，全服务默认最多同时下载两本（`JM_ARCHIVE_CONCURRENCY` 可设为 1–4，所有服务须保持一致），同一本互斥并在锁内复查缓存。缓存命中不占源站下载名额，上传和文字回复可以并行。

网页查看器、QQ 机器人和旧后台下载队列统一使用 `JM_DOWNLOAD_DIR`：图片为 `<漫画号>/`，ZIP 为 `.archives/<漫画号>.zip`，图片和 ZIP 的实际磁盘体积合计计入一个 LRU 预算，默认 **10 GiB（10,737,418,240 字节）**。网页读取图片、查看漫画、机器人请求和 ZIP 下载都会刷新访问时间；超过预算时优先淘汰最久未访问且未被占用的漫画。读取/传输持有共享锁，下载/淘汰持有排他锁。下载临时目录不属于已完成缓存，下载期间会临时额外占用磁盘；失败会清理临时目录。现有历史目录会纳入预算，但不把旧的部分章节缓存误判为完整漫画。

缓存图片从整本 ZIP 恢复后直接供网页使用，不重复从源站下载。整本仍限制最多 10 章。重启会中断尚未完成的进程内任务，需重新发消息；这不是持久化任务队列。

接口失败时回复中包含阶段、HTTP 状态、腾讯错误码、腾讯说明、trace_id 和本地请求编号，并尝试备用下载链接。接口拒绝发送任何消息时，错误只能记录在服务端。诊断保留 7 天，不保存聊天正文、用户 OpenID 或密钥。登录查看器后可访问 `/jm/api/cache` 查看缓存统计，`/jm/api/diagnostics/<请求编号>` 查看具体请求结果；沿用网页的密码保护。

反向代理需将 `/jm/` 去掉前缀后转发至 5003；`/qq/callback` 保持原路径转发。同一本缓存包可供多个签名链接使用。领取链接是临时访问凭证，请勿公开转发。

测试：在仓库根目录运行 `python -m unittest discover -s qq_bot -p 'test_*.py'`。测试使用合成图片及模拟 QQ 接口，不向真实用户发送消息。

默认及网页模式立即返回 `/jm/view/<漫画号>`，不提交后台下载或文件上传任务；打开网页后由查看器加载共享缓存。压缩包模式直发失败时提供网页及 ZIP 链接。分片上传按返回编号确定 1/0 起始偏移，确认接口仅对 40093001 按平台延迟配置重试（单片最多 120 秒）；整个上传最多 180 秒，并受原消息剩余回复窗口约束。图片模式每张最大 10 MiB（本服务限制），按自然页序从共享 ZIP 读取，不生成重复图片缓存。

机器人网页查询、搜索指令和 help 帮助会显示用户指定的网页登录密码 EXAMPLE_VIEWER_PASSWORD。授权会话使用 365 天持久 Cookie，访问自动续期；清除 Cookie、更换浏览器或无痕会话仍需重新登录。
